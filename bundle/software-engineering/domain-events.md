# Record meaningful occurrences

In [Domain-driven design](domain-driven-design.md), a domain event records that something meaningful happened in the domain, such as an order being accepted. Other parts of the model can react without hiding the causal change inside a direct call. Event delivery, ordering, duplication, and failure semantics remain explicit engineering decisions.[^domain-language-reference]

[^domain-language-reference]: Eric Evans, [Domain-Driven Design Reference](https://www.domainlanguage.com/wp-content/uploads/2016/05/DDD_Reference_2015-03.pdf).
